# «Лабораторная работа №3»

Тема: основы JavaScript.

В папке `lab3` лежит каркас проекта [js-tasks](https://github.com/teach-kirshdv/js-tasks). В файле `lab3/src/core.js` реализованы функции:

- `even` — массив чётных чисел от 2 до 20;

- `recSumTo` — сумма чисел до n через рекурсию;

- `fibonacci` — n-е число Фибоначчи;
- `getOperationFn` — функция с сохранённым значением (замыкание);
- `sequence` — генератор арифметической последовательности (замыкание);
- `deepEqual` — глубокое сравнение объектов.

# «Лабораторная работа №4»

Тема: современный CSS и основы ООП на JavaScript.

- `index.html` — Flexbox: структура страницы и два блока описания рядом.
- `switches.html` — Grid: структура страницы, описание с картинкой и таблица в двух колонках.
- `keyboards.html` — статическая таблица восьми клавиатур.
- `gallery.html` — шесть фотографий из `img`, сетка Grid, последовательное появление и увеличение при наведении.
- `form.html` — форма «Моя сборка»: клавиатура, переключатели, кейкапы, плейт, формат, цена. Три вида полей: текстовое (`text`), числовое (`number`) и выпадающий список (`select`).
- `style.css` — цвета в переменных `:root`, классы по БЭМ, анимация появления содержимого страниц.
- `script.js` — класс `Keyboard`, конструктор и метод `print()` для форматированного вывода в консоль.

Запуск: открыть `lab4/index.html` двойным щелчком. Установка пакетов и сервер не нужны.

Проверка формы: открыть «Моя сборка», открыть консоль разработчика, заполнить поля и нажать «Вывести в консоль». Создаётся объект Keyboard и вызывается print(). Пустые обязательные поля и отрицательная цена не допускаются.

Отправки на сервер нет. Данные формы только выводятся в консоль.


- `@keyframes page-appear` меняет `opacity` от 0 до 1 и `translateY` от 12px до 0. Анимация запускается при загрузке новой страницы; это появление содержимого, без анимации ухода старой страницы. При включённом уменьшении движения в настройках системы анимация отключается.

Галерея выполнена только на HTML/CSS: `repeat(3, 1fr)` задаёт три колонки (на узком экране две или одна). Карточки используют существующую анимацию `page-appear`, а `nth-child` задаёт задержки по 0.15 секунды. `backwards` применяет начальное состояние анимации до её старта. При наведении `scale(1.06)` увеличивает фотографию на 6%, `transition` делает это плавно, `overflow: hidden` удерживает фотографию в рамке. JavaScript для галереи не подключён.
