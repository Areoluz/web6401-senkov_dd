# «Лабораторная работа №3»

Тема: основы JavaScript.

В папке `lab3` лежит каркас проекта [js-tasks](https://github.com/teach-kirshdv/js-tasks). В файле `lab3/src/core.js` реализованы функции:

- `isInteger` — проверка на целое число через побитовый оператор;
- `even` — массив чётных чисел от 2 до 20;
- `sumTo` — сумма чисел до n через цикл;
- `recSumTo` — сумма чисел до n через рекурсию;
- `factorial` — факториал;
- `isBinary` — проверка, является ли число степенью двойки;
- `fibonacci` — n-е число Фибоначчи;
- `getOperationFn` — функция с сохранённым значением (замыкание);
- `sequence` — генератор арифметической последовательности (замыкание);
- `deepEqual` — глубокое сравнение объектов.

Запуск тестов:

```
cd lab3
npm install
npm test
```
